# Solar System Planet Picker Keyframe Animation

A modern and interactive **Solar System Planet Picker** built using **HTML, CSS, and JavaScript**.  
This project showcases smooth keyframe animations, animated planetary transitions, SVG-based curved navigation, and responsive UI interactions to create an engaging space-themed web experience.

---

## Overview

The application allows users to navigate through different planets in the solar system using an animated curved navigation interface. Each planet section dynamically updates with smooth transitions, animated statistics, and visually appealing motion effects.

Designed with a focus on animation and user experience, this project demonstrates creative frontend development techniques using pure web technologies.

---

## Features

- Interactive planet selection system
- Smooth keyframe-based animations
- Animated SVG curved navigation
- Dynamic planet information updates
- Responsive and modern UI design
- Animated numerical transitions
- Dark-themed immersive interface
- Pure HTML, CSS, and JavaScript implementation
